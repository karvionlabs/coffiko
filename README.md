# ☕ Coffiko — Artisan Cafe & Specialty Roastery Architecture

> **Coffiko**-এর রিভার্স-ইঞ্জিনিয়ার্ড আর্কিটেকচার, ডিজাইন সিস্টেম, ফিগমা টোকেন, ফ্রন্টএন্ড টেক স্ট্যাক এবং স্বয়ংসম্পূর্ণ ইন্টারেক্টিভ সিএমএস এডমিন প্যানেল।

---

## 📌 ১. ওভারভিউ ও প্রজেক্ট আইডেন্টিটি (Overview & Identity)

* **প্রজেক্টের নাম:** Coffiko Cafe & Specialty Roastery
* **মূল টেমপ্লেট রেফারেন্স:** [Webflow Brewlab Template](https://webflow.com/templates/html/brewlab-website-template)
* **ডিজাইনার স্টুডিও:** Orbix Studio (`hello@orbix.studio`)
* **ডিজাইন ফিলোসফি:** নিও-রেট্রো এডিটরিয়াল কফি নান্দনিকতা, বোল্ড টাইপোগ্রাফি, ওয়ার্ম ওট-মিল্ক ক্যানভাস এবং অর্গানিক ব্র্যান্ডিং।

---

## 🛠️ ২. টেক স্ট্যাক ও আর্কিটেকচার (Complete Tech Stack)

### ক. ফ্রন্টএন্ড (Frontend):
* **HTML5:** Semantic W3C মার্কআপ, OpenGraph মেটা ট্যাগ এবং Schema.org JSON-LD স্ট্রাকচার্ড ডেটা (`CafeOrCoffeeShop`, `Menu`, `MenuItem`)।
* **CSS3:** Modern CSS Grid, Flexbox, এবং CSS Custom Properties (`var(--...)`) ডিজাইন টোকেন ভিত্তিক স্টাইলিং।
* **JavaScript:** Modern ES6+, DOM Event Dispatching, রিয়্যাক্টিভ ডেটা বাইন্ডিং।

### খ. মোশন ও অ্যানিমেশন লাইব্রেরি (Motion & Libraries):
* **GSAP 3:** কোর মোশন টাইমলাইন ও ইজিং কন্ট্রোল।
* **ScrollTrigger:** ভিউপোর্টে স্ক্রল করার সাথে সাথে সেকশন ও কার্ড এন্ট্রান্স অ্যানিমেশন।
* **Micro-interactions:** ডুয়াল-লেয়ার ম্যাগনেটিক পিল বাটন (`.btn-magnetic`) এবং ইনফিনিট মারকুই স্ক্রলিং ব্যানার (`.marquee-track`)।

### গ. ব্যাকএন্ড ও ডেটাবেজ আর্কিটেকচার (Backend & Database):
* **Client-side Reactive CMS Data Store (`js/store.js`):** 
  * ব্রাউজার LocalStorage-এ স্বয়ংক্রিয়ভাবে পারসিস্টেড নো-এসকিউএল কালেকশন।
  * মেনু আইটেম, কাস্টমার অর্ডার, ভিআইপি লিডস এবং সাইট কনফিগারেশন সরাসরি ম্যানেজ করা যায়।
  * লাইভ ইভেন্ট লিসেনার থাকায় এডমিন প্যানেলে মেনু বা দাম পরিবর্তন করলে গ্রাহকের হোমপেজ পেজ রিফ্রেশ ছাড়াই স্বয়ংক্রিয়ভাবে আপডেট হয়ে যায়!
* **Serverless Production Alternative:** প্রডাকশন ডেপ্লয়মেন্টে Webflow CMS, Supabase, অথবা Firebase Firestore-এর সাথে সহজেই একীভূত করা যায়।

## 🎨 ৩. ডিজাইন সিস্টেম ও ফিগমা আর্কিটেকচার (Design System & Figma)

### ব্র্যান্ড কালার প্যালেট (Brand Colors):
| নাম | হেক্স কোড (Hex) | ব্যবহারের স্থান |
| :--- | :--- | :--- |
| **Brand Primary** | `#482820` | ডার্ক রোস্টেড কফি বিন, হেডিং, প্রাইমারি বাটন |
| **Brand Secondary** | `#FEBD02` | গোল্ডেন হানি, ক্রেমা অ্যাম্বার, স্টার রেটিং, ব্যাজ |
| **Canvas Background** | `#F8F5F1` | ওয়ার্ম ওট মিল্ক লিনেন ক্যানভাস ব্যাকগ্রাউন্ড |
| **Flame Accent** | `#F85119` | রোস্টেড সিনামন ফ্লেম, হট ডিল ট্যাগ |
| **Pure White** | `#FFFFFF` | প্রোডাক্ট ও টেস্টিমোনিয়াল কার্ড সারফেস |
| **Charcoal Text** | `#111827` | সুপঠিত ড্রিপ কফি বডি টেক্সট (Gray 900) |

### টাইপোগ্রাফি সিস্টেম (Typography System):
* **Display / Headings:** `Tanker` (Vintage Bold Grotesque OTF, 400 Weight)
  * H1: `clamp(3.2rem, 8vw, 8rem)` (লাইন হাইট: 88%)
  * H2: `clamp(2.4rem, 5vw, 4.5rem)` (লাইন হাইট: 100%)
  * H3: `clamp(1.8rem, 3.5vw, 3rem)` (লাইন হাইট: 110%)
* **Body Text:** `Interdisplay` / `Inter` (Geometric Modern Sans, 300, 400, 500, 600, 700 Weights)
  * Large: 18px, Regular: 16px, Small: 14px
* **Special Cursive:** `Smooch` (Google Fonts Script) — সিগনেচার অ্যাকসেন্ট ও ব্যাজ টেক্সটে ব্যবহৃত।

### ফিগমা টোকেন ও স্পেসিফিকেশন:
* `tokens/tokens.json`: ফিগমার **Tokens Studio** প্লাগইন এবং W3C স্ট্যান্ডার্ড সমর্থিত।
* `tokens/figma-spec.md`: লেআউট গ্রিড (12-Col Desktop, 4-Col Mobile), অটো-লেআউট এবং কম্পোনেন্ট ভেরিয়েন্ট নির্দেশিকা।

## 🚀 ৫. যেভাবে রান ও টেস্ট করবেন (Quick Start)

### পদ্ধতি ১: যেকোনো ব্রাউজারে সরাসরি ওপেন
যেকোনো ব্রাউজারে সরাসরি `index.html` অথবা `admin.html` ফাইলটি ডাবল ক্লিক করে রান করতে পারেন। কোনো সার্ভার ইন্সটল করা ছাড়াই সম্পূর্ণ সিস্টেম অফলাইনে কাজ করবে!

### পদ্ধতি ২: লোকাল সার্ভারের মাধ্যমে (Recommended)
টার্মিনালে কমান্ড দিন:
```bash
npm start
```
অথবা:
```bash
python3 -m http.server 5050
```
ব্রাউজারে গিয়ে ওপেন করুন: `http://localhost:5050`

## ⚡ ৬. এডমিন প্যানেল দিয়ে কী কী করতে পারবেন?

1. **নতুন কফি আইটেম যোগ করা (+ Add New Coffee):** নাম, দাম, রোস্ট ক্যাটাগরি এবং টেস্টিং নোটস লিখলে তাৎক্ষণিক হোমপেজের মেনুতে যুক্ত হয়।
2. **লাইভ অর্ডার ট্র্যাকিং (Live Orders):** হোমপেজে কোনো গ্রাহক "Order Now" বাটনে ক্লিক করলে এডমিন প্যানেলে তাৎক্ষণিক অর্ডার চলে আসে এবং স্ট্যাটাস পরিবর্তন করা যায়।
3. **ভিআইপি সাবস্ক্রাইবার তালিকা (VIP Leads):** হোমপেজের নিউজলেটারে যুক্ত হওয়া ইমেইল এড্রেসগুলো রিয়েল-টাইমে সেভ হয়।
4. **স্টোর সেটিংস (Store Settings):** দোকানের নাম ও হিরো এনাউন্সমেন্ট টেক্সট কাস্টমাইজ করা যায়।
